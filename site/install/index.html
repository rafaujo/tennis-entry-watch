Install Tennis Entry Watch

Add the tracker to your Home Screen for an app-like window and access to the latest cached tournament snapshot when you are offline.

Installed. You are already using Tennis Entry Watch as an app.

Android

  1. Open this site in Chrome.
  2. Tap the browser menu.
  3. Choose Install app or Add to Home screen.
  4. Confirm the installation.

iPhone and iPad

  1. Open this site in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen.
  4. Tap Add.
Updates: the app checks for fresh entry lists whenever it opens. If the network is unavailable, it falls back to the last successfully cached snapshot.

Push alerts and personal favourites are planned separately; installing the PWA does not enable notifications yet.
